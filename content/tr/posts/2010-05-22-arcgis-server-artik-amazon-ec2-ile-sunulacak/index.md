---
title: "ArcGIS Server artık Amazon EC2 ile sunulacak"
date: 2010-05-22
---

Konuya girmeden önce belirtmeliyim teknik terimleri Türkçe yazmak garip görünse de özen göstermek gerekiyor. Bulut üyelik tanımını İngilizce'de "Cloud Subscription" tamlamasından geliyor.

Giderek yaygınlaşan bulut hesaplama(cloud computing), uzaktaki dağıtık sistemler felsefesiyle kurulmuş bilgisayar ağlarında uygulamanızı çalıştırıp hesap sonuçlarını almanızı sağlıyor.

ESRI bu popülerleşen bilişim kültürüne yabancı kalmamak ve kullanıcılarının bu kültürden faydalanmasını sağlamak için ArcGIS Server 9.3.1 sürümünü Amazon Elastic Compute Cloud (EC2)  sunucularında çalışabilir şekilde 12 aylık teknik destek ile sunacağını açıkladı. Böylece şirketler kendi sunucularında ArcGIS Server çalıştırmak için sunucu barındırma ve diğer gerekli masrafları minimuma indirebilecekler.

ESRI’nin sunduğu bu çözümün adı: ArcGIS Server Cloud Bundle. Bu paketle birlikte gelen sunucu özellikleri ise;

- Sanal dört çekirdekli EC2 sunucu üzerinde bir yıllık ArcGIS Server Advanced Enterprise lisansı
- Çekirdek başına 2.0 GHz  işlem gücü
- 15 GB RAM
- 1,690 GB Harddisk
- Microsoft Windows Server 2008 64-bit işletim sistemi

Şunu da belirtelim, bu hizmet şimdilik Amerikan pazarı için sunuluyor ama ileride küresel pazara açılacağını biliyoruz.
